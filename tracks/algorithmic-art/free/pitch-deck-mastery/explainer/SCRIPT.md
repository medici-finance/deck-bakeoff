# SCRIPT — Medici for RWA tokens · explainer (`pitch-deck-mastery` messaging)

Design: **INVARIANT DRIFT** (algorithmic-art contender, `free` mode). Stage 1920×1080, 143s, 8 scenes. Auto-plays on load.

**Controls** — `?scene=N` jumps to a scene and plays from there; `Space` / `→` next scene; `←` previous; `P` pause/resume; `R` restart. `window.__player = {scene, t, total, seek(n), play(), pause(), scenes}` is exposed for tooling. No audio, no video, no TTS — VO below is read live or dubbed in post.

All motion is produced by one seeded p5.js generative system (the conserved collateral field described in `../../PHILOSOPHY.md`); every scene is a parameter trajectory over the same population, so the split, the invariant, the payoff and the refused liquidation are emergent, not drawn.

## Recording notes

- Record at 1920×1080. The stage is a fixed 1920×1080 box scaled to the window; a browser window at exactly 1920×1080 with no chrome gives a 1:1 capture.
- Reload before recording: the field is seeded per scene, so a fresh load is byte-identical every time.
- Let it auto-play from t=0; do not touch the keyboard mid-take (Space advances the scene).
- The progress bar at the bottom edge is 6px; crop it out if the film should be clean.
